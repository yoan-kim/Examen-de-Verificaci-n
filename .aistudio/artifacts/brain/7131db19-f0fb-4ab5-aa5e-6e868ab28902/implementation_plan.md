# 인 맞음 확인 시험 학습·채점 시스템 (모듈형 아키텍처 · 차수 누적 · 모의시험 · 학습 노트)

단일 HTML 파일로 합쳐져 있던 코드를 유지보수와 바이브코딩(문항 추가·수정·차수 누적)이 용이한 **React + TypeScript + CSS + 차수별 데이터 파일 분리 구조**로 재정비하고, **이전 차수(15차·16차) 전환**, **모의시험 탭(1번부터 순서대로 풀이)**, **개인 학습 노트 탭 및 채점 후 노트 자동 표시 기능**을 추가합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> 사전 질문에서 확정해주신 답변을 바탕으로 아래와 같이 설계했습니다.

- **모듈형 파일 구조 및 바이브코딩 최적화**: HTML, CSS(`index.css`), 차수별 시험 데이터, 채점 엔진, UI 컴포넌트를 역할별로 명확히 분리합니다. 향후 대화로 *"16차 몇 번 문제를 수정해줘"* 또는 *"17차 시험을 추가해줘"*라고 요청하시면 해당 데이터 모듈만 즉시 수정·누적할 수 있습니다.
- **15차 · 16차 기본 수록 및 우측 하단 차수 전환 버튼**:
  - 메인 화면에는 항상 **가장 최신 차수(현재 16차)**가 기본으로 표시됩니다.
  - 화면 **오른쪽 아래(우측 하단)**에 버전(차수) 전환 버튼을 배치하여 언제든 이전 차수(15차 등)를 선택해 시험을 보거나 노트를 작성할 수 있습니다.
- **모의시험 탭 (`모의시험` / `Simulacro`) 추가**:
  - `1회차(월)` ~ `5회차(금)` 외에 요일과 무관하게 **1번부터 마지막 번호(16차는 1~6번, 15차는 1~10번)까지 원래 번호 순서대로** 모든 문제를 풀 수 있는 `모의시험` 탭을 추가합니다.
  - 채점 기준은 동일하게 **핵심 성구(16차 6번, 15차 10번)는 띄어쓰기 무관 토씨 100% 일치**, 나머지 일반 문항은 **핵심 단어 포함 시 정답**으로 채점합니다.
- **학습 노트 탭 (`노트` / `Notas`) 및 채점 후 자동 표시**:
  - 별도의 `노트` 탭에서 각 문항의 문제와 모범 답안을 보며 개인 암기 팁이나 이해를 돕는 메모를 작성·저장할 수 있습니다.
  - 시험을 볼 때(채점 전)는 노트가 보이지 않으며, **채점 후에는 맞은 문제와 틀린 문제 모두 하단 결과창에 내가 작성한 노트가 자동으로 함께 표시**되고 바로 펼쳐보거나 내용을 수정·보완할 수 있는 버튼을 제공합니다.

## 1. Overview & Core Concept

- **What It Does**: 한국어 및 스페인어(100% 분리 인터페이스)를 지원하는 요한계시록 인 맞음 확인 시험 통합 학습 플랫폼입니다. 차수별 시험지 누적 관리, 요일별 회차 연습(성구 우선), 실전 모의시험(1번부터 순차 풀이), 그리고 개인 맞춤형 암기 노트 기능을 제공합니다.
- **Target Audience / Persona**: 회차별 시험을 준비하며 성구와 핵심 교리를 체계적으로 암기·복습하려는 한국어 및 스페인어권 수험생.
- **Key Value**: 차수가 거듭되어도 이전 차수 문제를 언제든 복습할 수 있고, 공부할 때 적어둔 개인 노트를 채점 직후 모든 문항에서 즉시 다시 확인하며 학습 효율을 극대화할 수 있습니다.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **초기 언어 선택**: `한국어` 또는 `Español` 선택 시 이후 모든 화면이 해당 언어로만 렌더링됩니다.
  2. **모드 및 회차 탭 전환**:
     - `1회차(월)` ~ `5회차(금)`: 핵심 성구 문제를 첫 번째로 풀고 회차별 범위를 연습합니다.
     - `모의시험` (`Simulacro`): 1번부터 마지막 문제까지 실제 시험지 순서 그대로 전 문항을 응시합니다.
     - `노트` (`Notas`): 시험이 아닌 학습 모드로서, 전 문항의 모범 답안을 확인하고 문제별 개인 이해 노트·암기 팁을 작성합니다.
  3. **채점 후 노트 연동 확인**:
     - 개별 채점 또는 전체 채점 버튼을 누르면, 정오답 여부와 관계없이 각 문항의 채점 피드백 영역 하단에 **내가 작성한 학습 노트**가 자동으로 표시되며, 노트를 열람·편집할 수 있는 버튼이 함께 제공됩니다.
  4. **우측 하단 차수(버전) 선택기**:
     - 화면 오른쪽 아래에 고정된 버전 선택 버튼을 클릭하면 `16차 (최신)`과 `15차 (이전 차수)` 목록이 열리며, 클릭 즉시 해당 차수의 시험지와 노트로 전환됩니다.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 정돈된 에듀테크 학습·평가 워크스페이스.
  - *Color Palette & Mood*:
    - **60% Dominant Canvas**: 차분한 슬레이트 오프화이트(`#F8FAFC`).
    - **30% Structural Surfaces**: 화이트 카드(`#FFFFFF`), 슬레이트 보더(`#E2E8F0`), 가독성 높은 다크 슬레이트 타이포그래피(`#0F172A`).
    - **10% Semantic Accents**: 회차/모의시험 활성 탭은 로열 블루(`#2563EB`), 노트 탭 및 노트 박스는 웜 앰버/인디고 포인트, 정답은 에메랄드(`#16A34A`), 오답은 레드(`#DC2626`).

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 차수별 데이터 모듈화 (Cumulative Edition Registry)**
  - *Chosen Approach*: 각 차수(15차, 16차 등)의 메타데이터(차수 번호, 제목, 범위, 성구 문항 번호)와 한/스페인어 문항 데이터를 독립된 데이터 구조로 관리하고, 배열의 마지막(또는 최신 지정) 항목을 기본 메인 차수로 로드합니다.
  - *Why*: 앞으로 새로운 차수를 추가하거나 특정 차수의 한국어/스페인어 문항 일부를 수정·삭제할 때 기존 차수에 영향을 주지 않고 안전하게 누적할 수 있습니다.
- **Decision 2: 브라우저 `localStorage` 기반 문항별 노트 영구 저장**
  - *Chosen Approach*: 사용자가 작성한 노트를 `{차수ID}_{언어}_{문항번호}` 키 구조로 브라우저에 자동 저장합니다.
  - *Why*: 페이지를 새로고침하거나 차수/회차를 이동해도 내가 작성한 소중한 학습 팁이 유지되며, 채점 직후 모든 문제에서 즉시 불러와 복습할 수 있습니다.

## 4. Technical Architecture & Data Strategy

- **Architecture & Component Diagram**:
```
┌─────────────────────────────────────────────────────────────────────────┐
│                         App (Root State Manager)                        │
│  - selectedLang: 'ko' | 'es' | null                                     │
│  - currentEditionId: '16' | '15' (기본값: 최신 '16')                     │
│  - activeTab: 1 | 2 | 3 | 4 | 5 | 'mock' | 'notes'                      │
│  - userNotes: Record<string, string> (localStorage 연동)                 │
└───────────┬───────────────────────────────────┬─────────────────────────┘
            │ (언어 선택 후)                     │ (우측 하단 고정)
            ▼                                   ▼
┌───────────────────────────────────────┐ ┌───────────────────────────────┐
│             ExamWorkspace             │ │     EditionSwitcherWidget     │
│  ├─ TopHeader (현재 차수 제목/언어변경)│ │  - 우측 하단 버전 선택 버튼    │
│  ├─ NavigationBar                     │ │  - 16차(최신) / 15차(이전) 전환│
│  │   ├─ 1회차(월) ~ 5회차(금)         │ └───────────────────────────────┘
│  │   ├─ 모의시험 (1번~끝번 순차 출제)  │
│  │   └─ 노트 (전 문항 학습 & 메모)     │
│  ├─ ExamView (회차 & 모의시험 모드)    │
│  │   ├─ QuestionCard                  │
│  │   └─ GradingFeedback + NoteViewer  │
│  └─ StudyNoteView (노트 탭 전용 화면)  │
└───────────────────────────────────────┘
```

- **Data Model & Edition Specification**:
  - **16차 시험 (`id: '16'`, 최신 기본값)**:
    - 범위: 복습, 계 22장, 핵심 성구 (계 22:18~19) — 총 6문항
    - 1~5회차: 6번 성구 우선 출제 후 회차별 문항 출제
    - 모의시험: 1번 → 2번 → 3번 → 4번 → 5번 → 6번 순서대로 출제
  - **15차 시험 (`id: '15'`, 이전 차수)**:
    - 범위: 복습, 계 21장, 핵심 성구 (계 8:3~4) — 총 10문항
    - 1~5회차: 10번 성구 우선 출제 후 회차별 문항 출제
    - 모의시험: 1번 → 2번 → ... → 10번 순서대로 출제
